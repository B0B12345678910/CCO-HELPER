# Case Clicker Hub (Vercel)
1. Get a free key at https://console.groq.com/keys
2. Push this folder to a GitHub repo (or `npx vercel` in this folder).
3. In Vercel: Project > Settings > Environment Variables, add GROQ_API_KEY = your key (optional GROQ_MODEL, default llama-3.3-70b-versatile). Redeploy.
